# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue, and do not
include real tokens, phone numbers or message content in the report.

You should get a first answer within a few days. Once a fix is released, the advisory is published
with credit to you, unless you prefer otherwise.

## Supported versions

Only the latest release gets security fixes. Upgrade notes are in the [README](README.md).

## Scope

Partyline's security model is described in the README under "Security model". Of most interest:
access between organizations, the trusted/untrusted marking of messages, token handling, and
anything that lets message content act as instructions.
